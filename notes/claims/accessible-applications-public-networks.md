# cisa-ztmm-dnad.13: Accessible Applications — maturity progresses from making mission-critical applications available only over private networks and VPNs to making all applicable applications available over open public networks to authorized users and devices.

**Source:** [[CISA ZTMM — Device Network App Data Pillars]] — CISA, *Zero Trust Maturity Model v2.0*, 2023

## The Claim

Applications should become accessible over public networks rather than requiring VPNs. (§5.4)

## Evidence

| Stage | Description |
|-------|-------------|
| **Traditional** | Makes some mission-critical applications available only over private networks and protected public network connections (e.g., VPN) with monitoring. |
| **Initial** | Makes some applicable mission-critical applications available over open public networks to authorized users via brokered connections. |
| **Advanced** | Makes most applicable mission-critical applications available over open public network connections to authorized users. |
| **Optimal** | Makes all applicable applications available over open public networks to authorized users and devices, where appropriate. |

## Confidence

**Rating:** HIGH
**Rationale:** HIGH. This directly aligns with OMB M-22-09's directive.
